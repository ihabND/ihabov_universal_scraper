API reference

Scraper API

Any public page as formatted HTML, or as structured JSON on supported sites. One endpoint for a page, one for a batch.

{# ---- Quickstart ---------------------------------------------------------------------- #}

Quickstart

  1. Get a key. Sign up, then create one on your dashboard.
  2. Make a call with the key in the X-API-Key header: 
    curl -H "X-API-Key: YOUR_API_KEY" \
  "https://ihabov-universal-scraper.fly.dev/scrape?url=https://example.com/"
    import requests

response = requests.get(
    "https://ihabov-universal-scraper.fly.dev/scrape",
    params={"url": "https://example.com/"},
    headers={"X-API-Key": "YOUR_API_KEY"},
    timeout=120,
)
response.raise_for_status()
print(response.json()["content"])
    const params = new URLSearchParams({ url: "https://example.com/" });
const response = await fetch(`https://ihabov-universal-scraper.fly.dev/scrape?${params}`, {
  headers: { "X-API-Key": "YOUR_API_KEY" },
});
if (!response.ok) throw new Error((await response.json()).detail);
console.log((await response.json()).content);
  3. Read the result. The page's HTML is in content; see the response fields.
{# ---- Authentication ------------------------------------------------------------------ #}

Authentication

Send your key in the X-API-Key header. An account can have up to {{ max_keys }} keys, for example one per program, and each can be revoked on its own. Keys start with sk_ and are shown once, when you create them. A missing, wrong or revoked key returns 401.

Note Never put the key in the URL: query strings end up in logs and browser history.

{# ---- GET /scrape ---------------------------------------------------------------------- #}

GET /scrape

GEThttps://ihabov-universal-scraper.fly.dev/scrape

Fetches one page and returns its HTML, or its data as JSON.

urlrequired
The page, starting with http:// or https://. URL-encode it (most HTTP libraries do this for you).
modehtml · json
html (default): the formatted HTML in content. json: the page's data in parsed, on supported sites only.
browserauto · never · always
auto (default): a plain request first, the headless browser only if the site blocks it (a bot check, or 202, 403, 429, 503), or if a JSON page that loaded fine lacks the data. never: no browser. always: straight to the browser, a few seconds slower.
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://ihabov-universal-scraper.fly.dev/scrape?url=https://scrapeme.live/shop/Bulbasaur/&mode=json"

  "content": null,

    "name": "Bulbasaur",
    "price": 63.0,
    "description": "Bulbasaur can be seen napping in bright sunlight. ...",
    "sku": "4391",
    "categories": ["Pokemon", "Seed"],
    "tags": ["bulbasaur", "Overgrow", "Seed"],

Response fields

FieldMeaning
urlThe normalized URL that was scraped.
status_codeThe status the target site returned.
oktrue if that status was below 400.
fetched_withhttp, or browser when the headless browser was used.
contentThe formatted HTML with mode=html, otherwise null.
parsedAn object or a list of objects with mode=json, otherwise null.

Note ok and status_code describe the page, not the API call. A page that returns 404 still comes back as a 200 with "ok": false, so you can see the error page.

{# ---- POST /scrape/batch ------------------------------------------------------------- #}

POST /scrape/batch

POSThttps://ihabov-universal-scraper.fly.dev/scrape/batch

Scrapes up to 50 URLs in one call, each handled exactly like GET /scrape. A URL that fails is reported next to it and doesn't fail the rest.

urlsrequired
1 to 50 URLs. The same page listed twice is scraped once.
modehtml · json
Applied to every URL. Default html.
browserauto · never · always
Applied to every URL. Default auto.
import requests

urls = [
    "https://www.knjizare-vulkan.rs/domaci-klasici/25486-tvrdava",
    "https://example.com/",
]
response = requests.post(
    "https://ihabov-universal-scraper.fly.dev/scrape/batch",
    json={"urls": urls, "mode": "json"},
    headers={"X-API-Key": "YOUR_API_KEY"},
    timeout=300,
)
response.raise_for_status()

for item in response.json()["results"]:
    if item["status"] == 200:
        print(item["result"]["parsed"]["name"])
    else:
        print(item["url"], "failed:", item["detail"])
{
  "results": [
    { "url": "https://www.knjizare-vulkan.rs/domaci-klasici/25486-tvrdava", "status": 200,
      "result": { "url": "...", "status_code": 200, "ok": true, "fetched_with": "http", "content": null, "parsed": { "name": "TVRĐAVA", ... } },
      "detail": null },
    { "url": "https://example.com/", "status": 400, "result": null,
      "detail": "JSON isn't available for this page. Supported sites: ..." }
  ],
  "succeeded": 1,
  "failed": 1
}

results keep the order of urls. Each has the url as sent, a status (200 or the error /scrape would return), and either a result shaped like a /scrape response or a detail message.

Note Every URL counts against your rate limit, and a batch that doesn't fit is refused whole with 429. At most 4 URLs of one site are fetched at once, so batches that need the browser can take a few minutes.

{# ---- Errors -------------------------------------------------------------------------- #}

Errors

Errors use standard status codes and a JSON body with a detail message, like {"detail": "Invalid URL, only HTTP and HTTPS."}.

StatusMeaning
400Invalid URL or scheme, JSON on an unsupported site, or browser=always while the browser is off.
401The API key is missing, wrong or revoked.
403The URL points to a private or internal address.
413The page is larger than 5 MB.
415Not an HTML page, like a PDF, image or JSON file.
422A parameter is missing or invalid; detail lists which.
429Rate limit reached. The body has error; wait Retry-After seconds.
502The site is down, timed out, blocked or redirected too often, or the JSON data wasn't on the page.
503Every headless browser was busy for 15 seconds. Try again shortly.

Rate limits

  • {{ user_limit | capitalize }} per account, shared by all its keys and the web app, in a moving window (any 60 seconds).
  • Every URL counts, cache hits too: a batch of 5 uses 5. Your dashboard shows what's left.
  • Requests with a missing or wrong key: {{ ip_limit }} per IP address. Over a limit you get 429 with Retry-After.
Header on successMeaning
X-RateLimit-LimitRequests the window allows.
X-RateLimit-RemainingRequests left right now.
X-RateLimit-ResetSeconds until the window is completely free again.
{# ---- Good to know -------------------------------------------------------------------- #}

Good to know

  • Use a client timeout of at least 120 seconds. A slow site can use the whole 25-second fetch and then a browser run.
  • HTML pages only, up to 5 MB.
  • Results are cached for 10 minutes (30 seconds for error pages), shared by both modes. Cached answers still count.
  • Redirects are followed, up to 5, and every hop is checked against the internal-address block.
  • The first request after a quiet period takes 2 to 5 seconds longer while the server wakes up.
How fetching works
  • Plain fetch: 10 seconds per request to the site, 25 seconds in total including retries, waits and redirects. Then the page counts as unreachable: 502, or the browser with browser=auto.
  • Retries: up to 3, with growing waits, on timeouts and on 429, 502, 503, 504, as long as they fit in the 25 seconds.
  • Browser: up to 2 at a time; a request waits up to 15 seconds for one, then gets 503. 30 seconds to load, up to 20 for a bot check, up to 5 for scripts. Images, fonts and video aren't loaded, and every request the browser makes is checked against the internal-address block.
  • JSON mode in the browser stops as soon as the data is on the page.
  • Sites that block: with browser=auto, a site that blocked a plain request goes straight to the browser for 10 minutes. Cookies from a passed bot check are kept for 20 minutes for your account only, and later pages are tried over plain HTTP with them first, which is much faster.
  • Cache: separate per browser option, and shared by mode=html and mode=json, so asking for both fetches the page once.
  • Batches: 8 URLs at a time, at most 4 per site, started at least 0.25 seconds apart. Batch URLs wait up to 2 minutes for a free browser instead of 15 seconds.
