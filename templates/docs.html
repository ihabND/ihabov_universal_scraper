API Docs

Fetch any public web page and get back its formatted HTML, or, on supported sites, the page's data as structured JSON. The scraper uses a real browser's network fingerprint, follows redirects safely, and blocks requests to internal addresses.

Authentication GET /scrape Response JSON mode Errors Rate limits Examples Limits

Base URL

https://ihabov-universal-scraper.fly.dev

Authentication

Every request needs an API key, sent in the X-API-Key header. Keys are handed out personally; there is no sign-up.

X-API-Key: YOUR_API_KEY

Don't put the key in the URL, since query strings end up in logs and browser history. A missing or wrong key returns 401.

GET /scrape

Fetches a page and returns its content.

Query parameters

NameTypeRequiredDescription
urlstringYes The page to scrape. Must start with http:// or https://. URL-encode it if it contains & or ? (most HTTP libraries do this for you).
modestringNo html (default): the full HTML, formatted, as one string in content.
json: the page's data as structured JSON in parsed. Only works on supported sites.
browserstringNo auto (default): fetch the page normally, and only if the site blocks it (a bot check, or status 202, 403, 429 or 503), try again with a real headless browser. With mode=json, also when a page that loaded fine doesn't contain the expected data (an error page like a 404 is not retried).
never: don't use the browser.
always: go straight to the browser, for sites you know need it. Slower: a few seconds per page.

Response

A successful call returns 200 with this JSON body:

FieldTypeDescription
urlstringThe normalized URL that was scraped.
status_codeintegerThe HTTP status the target site returned.
okbooleantrue if the target site's status was below 400.
fetched_withstringhttp for a normal fetch, browser when the headless browser was used.
contentstring or nullThe formatted HTML with mode=html, otherwise null.
parsedobject, array of objects or nullThe page's data with mode=json, otherwise null. See JSON mode.

ok and status_code describe the page, not the API call. A page that returns 404 still comes back as a 200 from the API, with "ok": false, so you can see the error page's content.

Example response (mode=html)

{
  "url": "https://example.com/",
  "status_code": 200,
  "ok": true,
  "fetched_with": "http",
  "content": "<!DOCTYPE html>\n<html lang=\"en\">\n <head>\n  <title>\n   Example Domain\n  </title>\n ...",
  "parsed": null
}

Errors

Errors use standard HTTP status codes and a JSON body with a detail message:

{
  "detail": "Invalid URL, only HTTP and HTTPS."
}
StatusMeaning
400The URL is invalid, or uses a scheme other than http/https, or mode=json was sent for a page that isn't supported, or browser=always was sent to a server where the browser is turned off.
401The API key is missing or wrong.
403The URL points to a private or internal address (like localhost or 192.168.x.x), which is not allowed.
413The page is larger than 5 MB.
415The URL is not an HTML page (for example a PDF, image or JSON file).
422A parameter is missing or has an invalid value, like mode=pdf. The detail field is a list saying which parameter is wrong.
429Rate limit exceeded. The body is {"error": "Rate limit exceeded: 10 per 1 minute"}.
502The page couldn't be fetched: the site is down, timed out, or redirected too many times. With mode=json, also when the page didn't contain the expected data (for example a 404 page, or the site changed its layout).
503Every headless browser was busy for 15 seconds. Wait a moment and try again.

Rate limits

Each client IP address can make 10 requests per minute. Requests over the limit get 429; wait a minute and try again.

Examples

curl

curl -H "X-API-Key: YOUR_API_KEY" \
  "https://ihabov-universal-scraper.fly.dev/scrape?url=https://scrapeme.live/shop/Bulbasaur/&mode=json"

Python

import requests

response = requests.get(
    "https://ihabov-universal-scraper.fly.dev/scrape",
    params={"url": "https://scrapeme.live/shop/Bulbasaur/", "mode": "json"},
    headers={"X-API-Key": "YOUR_API_KEY"},
    timeout=120,
)
response.raise_for_status()

print(response.json())

JavaScript

const params = new URLSearchParams({ url: "https://example.com", mode: "html" });

const response = await fetch(
  `https://ihabov-universal-scraper.fly.dev/scrape?${params}`,
  { headers: { "X-API-Key": "YOUR_API_KEY" } },
);
if (!response.ok) throw new Error((await response.json()).detail);

const data = await response.json();
console.log(data.content);

Limits and behaviour

WhatLimit
Page size5 MB
Timeout per request to the target site10 seconds
Total time for the plain fetch25 seconds, covering all retries, waits between them and redirect hops. After that the page counts as unreachable (502, or the browser with browser=auto).
RetriesUp to 3, with increasing waits, on timeouts and on 429, 502, 503, 504 from the target site, as long as they fit in the 25 seconds
RedirectsFollowed automatically, up to 5. Every hop is checked against the internal-address block.
Content typesHTML only (text/html, application/xhtml+xml)
BrowserUp to 2 at a time (a request waits up to 15 seconds for a free one, then gets 503), 30 seconds to load the page, up to 20 seconds for a bot check to finish, and up to 5 seconds for scripts to finish rendering. Images, fonts and video are not loaded. Every request the browser makes is checked against the internal-address block, and redirect hops are checked after the page loads.

First request after a quiet period: the server sleeps when idle, and waking it adds 2 to 5 seconds. Use a client timeout of at least 120 seconds: a slow site can use the whole 25-second fetch budget and then a full browser run on top.
